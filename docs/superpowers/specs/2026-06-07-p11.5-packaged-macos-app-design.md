# P11.5 — Packaged macOS App Design

Date: 2026-06-07
Status: Approved for implementation
Author: agentic-os team
Builds on: P11 (`specs/028-desktop-app-shell.md`)
Blocks: P12 (`specs/030-remote-access-adapter.md`)

## Summary

Make `pnpm desktop:build` produce a **standalone macOS `.app`** that opens the existing web UI,
starts/stops **bundled** `agentd` + UI server resources, and **always converges** lifecycle on
Quit, crash, and relaunch — with **no dependency on repo root** and **no orphaned processes**.

P11.5 is **bundle + lifecycle only**. No new product features, no remote connection logic.

## Locked decisions

| Topic | Decision |
|-------|----------|
| Platform | **macOS validated only**; Windows/Linux bundle paths documented, not gated |
| Scope | Bundle layout, resource resolution, build pipeline, lifecycle convergence |
| Out of scope | Code signing/notarization, auto-update, iOS, remote gateway, pairing, token, SSE (P12) |
| Dev path | `pnpm desktop:dev` unchanged — still uses repo `scripts/` + `AGENTIC_OS_ROOT` |
| Prod path | `.app` uses Tauri `resource_dir()` + bundled `agentic-os/` tree |
| State | Runtime state stays under `~/.agentic-os` (PID files, logs, SQLite) |
| Registry default | Ship `examples/agents.toml` inside bundle; operator may override via env later |
| Build hook | `beforeBuildCommand` **assembles resources only** — never starts daemon/UI |
| agentd binary | Bundle a frozen venv (`uv sync` into staging) invoked by `desktop-daemon.sh` |
| UI server | Bundled `apps/web` copy + system `python3 -m http.server` (no new bundler) |

## Problem statement (P11 gaps)

1. **Resource discovery** — Rust/scripts locate repo via `AGENTIC_OS_ROOT` or `pyproject.toml` walk; packaged `.app` has neither.
2. **Build side effects** — `beforeBuildCommand` starts daemon/UI during `tauri build`, leaving background processes.
3. **Lifecycle leaks** — SIGKILL / crash / relaunch can leave listener PIDs or stale PID files; tray Quit path must remain idempotent.
4. **No bundle smoke gate** — P11 merge required `desktop:dev` only.

## Architecture

```
pnpm desktop:build
  └─ prepare-desktop-bundle.sh   # copy web, scripts, registry; uv sync → staging/runtime
  └─ tauri build                 # bundle Resources/agentic-os/**

agentic-os.app (macOS)
  Contents/Resources/agentic-os/
    scripts/          desktop-daemon.sh, desktop-ui.sh, lib/
    web/              copy of apps/web
    registry/         agents.toml (default harness registry)
    runtime/.venv/    agentd + deps (uv-built at compile time)

  Tauri (release)
    bundle_root() → resource_dir()/agentic-os
    run_script() sets AGENTIC_OS_BUNDLE_ROOT, AGENTIC_OS_STATE_DIR (unchanged default)
    setup: start_stack() with bundled scripts
    quit + RunEvent::Exit: stop_stack() (idempotent)
    relaunch: adopt or replace stale listeners on ports 8767/5173
```

## Bundle root resolution

| Mode | Root | Scripts | Web | agentd |
|------|------|---------|-----|--------|
| Dev (`tauri dev`) | `repo_root()` | `repo/scripts/` | `repo/apps/web` | `rtk uv run agentd` |
| Release (`.app`) | `bundle_root()` | `Resources/agentic-os/scripts/` | `Resources/agentic-os/web/` | `runtime/.venv/bin/agentd` |

Rust exposes one helper:

```rust
fn runtime_root() -> PathBuf {
  if cfg!(debug_assertions) { repo_root() }
  else { bundle_root().unwrap_or_else(repo_root) }
}
```

Scripts honor `AGENTIC_OS_BUNDLE_ROOT` when set; `desktop_root()` becomes bundle root in release invocations.

## Lifecycle convergence rules

| Event | Required behavior |
|-------|-------------------|
| Tray **Quit** | `stop_stack()` then `app.exit(0)`; both UI + agentd down; PID files cleared |
| `RunEvent::Exit` | `stop_stack()` (idempotent second call) |
| **Crash** / force-kill | Next launch: detect port listeners; if PID file stale, adopt or stop-and-restart managed stack |
| **Relaunch** while running | Single-instance: focus existing app OR stop orphaned listeners before `start_stack()` |
| `desktop:build` completes | No agentd/UI processes left from build |

## Acceptance criteria (merge gate)

Manual macOS smoke after `pnpm install && pnpm desktop:build`:

1. Open `agentic-os.app` — web UI visible at bundled localhost URL.
2. Tray shows `agentd: ok`.
3. Tray Stop → `down`; Start → `ok`.
4. Tray Quit → no `agentd` or `http.server` on 8767/5173.
5. Relaunch app — clean start, no duplicate listeners.
6. `pnpm desktop:dev` still passes P11 smoke (no regression).

Automated where cheap:

- `prepare-desktop-bundle.sh` dry-run or staging dir layout test
- Existing `tests/test_desktop_scripts.py` with `AGENTIC_OS_BUNDLE_ROOT` pointed at a fixture tree
- `cargo test` for `runtime_root()` / path helpers

## P12 boundary (explicit non-goals)

P12 owns **remote** only via the **Remote Access Adapter**:

- remote gateway / reverse tunnel wire-up (transport-agnostic; not tied to frp/Tailscale/CF/ngrok)
- device pairing + revoke flow (`pairing_code`, `device_id`)
- token storage/use for remote API (`gateway_url`, `auth_token`)
- event stream (SSE/WebSocket) client in desktop + iOS
- **`agentd` remains on `127.0.0.1` only** — gateway is the sole external entry

P11.5 may keep `desktop.toml` `[remote]` placeholders read/write; no connection logic.

## Risks

| Risk | Mitigation |
|------|------------|
| Bundle size (full venv) | Accept for P11.5; slim runtime is post-P12 optimization |
| System Python for http.server | Document minimum macOS Python; optional bundle python later |
| uv unavailable on build machine | CI/build docs require `uv`; `prepare-desktop-bundle.sh` fails fast |
| External agentd on 8767 | Same as P11: `managed: false` + tray shows ok; stop only kills managed PID |
