# P11.5 Packaged macOS App Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task.

**Goal:** `pnpm desktop:build` → standalone `.app` with bundled agentd/UI resources, convergent lifecycle, no repo-root dependency.

**Architecture:** `prepare-desktop-bundle.sh` stages `web/`, `scripts/`, `registry/`, `runtime/.venv/` into Tauri resources. Release Rust sets `AGENTIC_OS_BUNDLE_ROOT`. Scripts branch on bundle vs dev root. Build hook does not start processes.

**Tech Stack:** Tauri 2 bundle resources, bash lifecycle scripts, `uv sync` for bundled venv, existing `agentd` Python package.

**Design reference:** `docs/superpowers/specs/2026-06-07-p11.5-packaged-macos-app-design.md`

## Task 1: Bundle staging script

- [ ] Create `scripts/prepare-desktop-bundle.sh`
  - Output dir: `apps/desktop/src-tauri/bundle-resources/agentic-os/`
  - Copy: `scripts/desktop-*.sh`, `scripts/lib/`, `apps/web/`, `examples/agents.toml` → `registry/`
  - Run: `uv sync --directory <repo> --python 3.12` with `--prefix` or copy `.venv` into `runtime/.venv`
  - Print staged file manifest; exit non-zero if `agentd` missing in venv
- [ ] Add `bundle-resources/` to `.gitignore` (generated at build time)
- [ ] Test: `bash scripts/prepare-desktop-bundle.sh && test -x .../runtime/.venv/bin/agentd`

---

## Task 2: Script bundle-root awareness

- [ ] `desktop-common.sh`: `desktop_root()` → `$AGENTIC_OS_BUNDLE_ROOT` if set, else repo walk
- [ ] `desktop-daemon.sh`: when bundle root set, use `$ROOT/runtime/.venv/bin/agentd` and `$ROOT/registry/agents.toml`
- [ ] `desktop-ui.sh`: when bundle root set, `--directory "$ROOT/web"`
- [ ] Keep dev path (`rtk uv run`) when bundle root unset
- [ ] Extend `tests/test_desktop_scripts.py` with tmp bundle fixture + `AGENTIC_OS_BUNDLE_ROOT`

---

## Task 3: Tauri resource wiring

- [ ] `tauri.conf.json`:
  - Replace `beforeBuildCommand` with `bash ../../scripts/prepare-desktop-bundle.sh`
  - Add `bundle.resources`: `["bundle-resources/agentic-os"]`
  - Keep `frontendDist` for webview assets (or align with bundled web URL — prefer localhost server for parity with P11)
- [ ] `daemon.rs`:
  - `bundle_root(app: &AppHandle) -> Option<PathBuf>` via `app.path().resource_dir()?.join("agentic-os")`
  - `runtime_root()` dev vs release
  - `run_script()` sets `AGENTIC_OS_BUNDLE_ROOT` in release
- [ ] `cargo test` for path resolution helpers with temp dirs

## Task 4: Lifecycle convergence

- [ ] `lib.rs` setup: before `start_stack()`, call reconcile helper:
  - If PID file pid dead but port listening → adopt listener PID (existing script logic) OR stop port owner if same bundle session marker
- [ ] Tray Quit + `RunEvent::Exit`: keep idempotent `stop_stack()` (already in P11)
- [ ] Optional: `tauri-plugin-single-instance` — second launch focuses tray window
- [ ] Document: SIGKILL leaves orphans (OS limitation); relaunch must self-heal via reconcile
