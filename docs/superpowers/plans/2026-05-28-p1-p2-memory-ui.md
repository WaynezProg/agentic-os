# P1 P2 Memory Pipeline And Thin UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build P1 Harness Run evidence pipeline and P2 thin browser control panel without breaking the P0 daemon/CLI contract.

**Architecture:** P1 adds deterministic memory services backed by SQLite tables and daemon API routes. P2 adds a no-build static web app that calls daemon APIs only; it never owns underlying harness work.

**Tech Stack:** Python 3.12, FastAPI, Typer, SQLite/FTS5 where available, pytest, ruff, static HTML/CSS/JavaScript served by `python -m http.server`.

---

## Context

P0 already provides:

- TOML Harness Instance Registry and command rendering.
- `agentd serve` FastAPI daemon.
- `agentctl` CLI for agents, sessions, logs, stop, and retry.
- SQLite Harness Sessions/events, JSONL logs, artifact folders, `session.json`.
- process-group start/stop/retry/reconcile.

P1/P2 must preserve those contracts.

```python
from __future__ import annotations

from dataclasses import dataclass

from agentic_os.logs import LogEntry
from agentic_os.models import SessionRecord


@dataclass(frozen=True)
class BuiltSummary:
    one_liner: str
    last_task: str
    last_branch: str
    stopped_at: str | None
    stdout_lines: int
    stderr_lines: int
    error_lines: int


def build_session_summary(session: SessionRecord, entries: list[LogEntry]) -> BuiltSummary:
    stdout = [entry.line for entry in entries if entry.stream == "stdout" and entry.line.strip()]
    stderr = [entry.line for entry in entries if entry.stream == "stderr" and entry.line.strip()]
    first_signal = stdout[0] if stdout else (stderr[0] if stderr else "")
    one_liner = first_signal[:160] if first_signal else f"{session.agent_id} session {session.status.value}"
    error_lines = sum(1 for line in stderr if "error" in line.lower() or "failed" in line.lower())
    stopped_at = session.ended_at if session.status.value == "stopped" else None
    return BuiltSummary(
        one_liner=one_liner,
        last_task=one_liner,
        last_branch="",
        stopped_at=stopped_at,
        stdout_lines=len(stdout),
        stderr_lines=len(stderr),
        error_lines=error_lines,
    )
```
